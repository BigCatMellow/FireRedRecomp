# FireRed ReComp behavior ledger

This is the evidence index for claims of parity. A subsystem is not complete
merely because it has code: it needs a source/data basis, automated evidence,
and a reachable runtime path where applicable. Add a row whenever a subsystem
becomes player-visible; do not silently replace the source basis with a
convenient approximation.

## Evidence scope

This correction follows the [accepted nine-row audit](../work/reports/phase0-behavior-ledger-audit.md)
at `61f1a77` and its [independent review](../work/reviews/2026-09-27-behavior-ledger-audit-review.md).
Its runtime/source map is pinned to repository `eac7d69` and public reference
`c75f352304d529f6ba92d4f74b9cf8b5c3810788`; the audit supplies exact source
locations. The save row additionally retains accepted rollover `aec377a`,
reconciled at `9c81b90`. Links navigate the repository; those pins and named
receipts qualify the claims, not whichever revision a link later displays.

Source citation, runtime wiring, inspected assertions, recorded execution and
independent acceptance are distinct. Test links below describe assertions, not
new test runs. **Recorded suite execution** means the [Pain Split receipt](../work/reviews/2026-09-20-pain-split-implementation-review.md)
at `a739ddc`, run `35493728001`: both 149-file suites, including verified-ROM
execution of tests unchanged at the audit pin. Only two save-test files changed
in the audit's path-limited comparison; their later evidence is separate below.
This suite receipt is not independent acceptance of every covered subsystem.
UNKNOWN means the specified proof was not located, not that behavior is absent.
